HTTP: запрос и ответ

Клиент и сервер общаются по протоколу HTTP. Каждый разговор — это пара «запрос → ответ».

Запрос (request) состоит из:
    - метода — что хотим сделать (см. ниже);
    - пути (URL) — к чему обращаемся, например '/', '/todos'
    - заголовков — доп. информация (например, формат данных);
    - тела — данные, которые отправляем (не у всех запросов есть).

Ответ (response) состоит из:
    - статус-кода — чем всё закончилось (см. ниже);
    - заголовков;
    - тела (response data) — данные, которые вернул сервер (обычно в формате JSON).

CRUD - CREATE/READ/UPDATE/DELETE
HTTP-методы (и операции CRUD)
    GET - прочитать/посмотреть - Read
    POST - создать - Create
    PUT - изменить - Update
    PATCH - изменить - Update
    DELETE - удалить - Delete

SOFT DELETE - скрыть
let todo = {

    title: 'Hello',
    isCompleted: true,
    isDeleted: true
}

PUT:
let todo = {
    id: 1,
    title: 'Hello',
    isCompleted: true
}
todo = {
    id: 1,
    title: 'Hello 2',
    isCompleted: true
}

PATCH
let todo = {
    id: 1,
    title: 'Hello',
    isCompleted: true
}
todo.title = 'Hello 2'


Статус-коды ответа
Трёхзначное число, которое говорит, чем закончился запрос:

200 OK — успех;
201 Created — успешно создано;
400 Bad Request — клиент прислал что-то не то;
401 Unauthorized — нужно авторизоваться;
404 Not Found — не найдено;
500 Internal Server Error — упал сам сервер / бэкендер что то сделал не так.
Правило: коды 2xx — успех, 4xx — ошибка клиента, 5xx — ошибка сервера.
